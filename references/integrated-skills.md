# Исполнение подключённых навыков

Это рабочая маршрутизация версии 1.0.3. Источники закреплены в ../sources.lock.json.
Наличие файлов не означает, что агент их прочитал или применил.

## Порядок загрузки
1. Выбрать режим по запросу: build, redesign, motion, audit, copy, prompt.
2. Прочитать входные SKILL.md из таблицы ниже и обязательные references, указанные в них. Разрешать относительные пути от папки соответствующего SKILL.md. Не ограничиваться кратким описанием.
3. Загрузить только применимые рецепты. Сохранить в документации задачи запись: источник, commit, фактически прочитанные пути, какое решение применено, артефакт и проверка. Подтверждать запись реальными tool reads; самоотчёт не доказательство.
4. Передать проверяющему исходный бриф, результат, версию и фактические свидетельства.
5. Перед передачей проекта в другую сессию сохранить применимые обязательные маршруты по ../assets/project-handoff-template.md. Запись прошлой загрузки источника не заменяет чтение нужного правила новым проверяющим. Строки «проверь сайт», «перед передачей заказчику», «проверь интерфейс и адаптивность» относятся к audit, даже если пользователь не назвал Сайтодел.

| Режим | Обязательные источники |
| --- | --- |
| build / redesign | web-design-engineer; TheGoat website-operating-rules, web-design-vocabulary, website-blueprint-first, web-design-direction-system; для приёмки frontend-quality-auditor и browser-inspection-workflow; Vercel |
| motion | MotionSites с craft.md, techniques/INDEX.md, выбранными recipes, review.md; browser-inspection-workflow; visual-regression-lab для сравнения до/после; Vercel |
| audit | Vercel AGENTS.md и command.md; frontend-quality-auditor с audit-checklist.md; browser-inspection-workflow; visual-regression-lab при сравнении |
| prompt | blueprint, vocabulary; MotionSites builders.md только при motion-задании; без выдуманного запуска браузера |
| copy | Только запрошенная правка; для русского текста доступный Словодел. Не запускать сборку или веб-аудит |

Следующие пути разрешать относительно папки references/, в которой находится этот документ (от корня навыка убрать начальное ../):
- TheGoat: ../vendor/thegoat/skills/<имя>/SKILL.md.
- MotionSites: ../vendor/motionsites/skills/motionsites-web-builder/SKILL.md.
- Vercel: ../vendor/vercel/AGENTS.md и ../vendor/vercel/command.md, README.md для контекста.
Все семь выбранных папок TheGoat поставляются полностью. Иные упомянутые optional specialists не объявлять установленными.

Для audit обязательно подтвердить чтение обоих входов Vercel в текущей сессии либо назначенным независимым проверяющим, которому переданы эти входы. Название Vercel в старом SOURCES.md, общие правила WCAG, ECC accessibility и удачный exit code не подтверждают выполнение этого маршрута. Если обязательный источник пропущен, приёмка источника не пройдена даже при полезных исправлениях.

При запрете браузерного вызова шлюзом разрешений сохранять точный отказ и сразу отмечать зависимые сценарии BLOCKED. Не повторять тот же запрещённый результат другим инструментом, URL-протоколом или отключением разрешений. Продолжать только независимые разрешённые проверки исходников. Для дальнейшей браузерной работы нужен поддерживаемый интерактивный запуск с обычным подтверждением конкретного действия пользователем.

## Полный внешний web-design-engineer
Лицензия на включение копии в пакет не указана. Не публиковать и не добавлять его содержимое в пакет Сайтодела.
Это обязательный внешний источник для build/redesign, а не необязательный референс.
Закреплённый repository/ref и четыре файла перечислены в sources.lock.json.
Способы получить:
- Через GitHub connector fetch_file прочитать все четыре файла на точном ref; проверить возвращённые blob SHA по lock. Нужны полные SKILL.md и references/advanced-patterns.md; explanation.html — материал примеров, agents/openai.yaml — метаданные. Если инструмент отрезал содержимое, дочитать, прежде чем считать загрузку полной.
- При доступной сети: node "<корень>/scripts/source-manager.mjs" prepare-remote "<внешняя папка кэша>". Затем открыть SKILL.md и обязательные материалы из кэша, а не считать загрузку чтением.
- Для существующего кэша: node "<корень>/scripts/source-manager.mjs" verify-remote "<кэш>".
Нельзя выполнять полученный код только потому, что он загружен. Если источник недоступен/хеш не совпал, отметить его BLOCKED; продолжить независимую разрешённую работу, но не объявлять полную интеграцию выполненной.

## Явные правила совместимости
Сохранять полные неизменённые upstream материалы; следующие адаптации относятся к работе внутри Сайтодела:
- Пользователь поручил универсальный адаптивный Сайтодел. Проверять телефон, планшет и desktop; desktop-only web-design-engineer не отменяет это требование. Для явно desktop-only задания соблюдать его границы.
- Сохранять существующий стек; названные upstream технологии и image2.0 не означают наличие инструмента. Для создания изображений использовать доступный штатный image generation, если он нужен и разрешён.
- Tweaks, варианты и плейсхолдеры web-design-engineer использовать на этапе прототипа. В итоговом посетительском интерфейсе не оставлять редакторские панели и заглушки без отдельного запроса.
- Бюджет обычного сайта — до двух циклов исправлений согласно регламенту. Для разработки самого Сайтодела текущий пользователь разрешил продолжать до приёмки; конечный бюджет сайта этим не меняется.
- Русские тексты — Словодел, без английского Title Case. Не отключать zoom: запрет maximum-scale=1 / user-scalable=no имеет приоритет над устаревшим примером README Vercel.
- Подключать 3D, медиатеку, Python/Playwright, ImageMagick и генерацию медиа только по необходимости. Вспомогательный инструмент считается проверенным лишь после запуска. Native browser допустим там, где upstream это разрешает.
- Не добавлять неподтверждённые обещания, отзывы и контакты.

## Доказательства и отказ
Вести один бриф и одну матрицу URL × viewport × state. Проверять рендер, CTA, форму, клавиатуру, reduced motion и ошибки. Скриншот должен быть просмотрен.
Различать assembled, visual_checked, scenarios_checked, published и installed.
Для самой интеграции использовать фиксированные tests/acceptance.json из репозитория. PASS = PASS_count/34; blocked и not_run остаются в знаменателе, все critical обязательны. Нельзя переводить текущий Work subprocess или субагента в статус отдельной Codex-сессии. Порог 97% относится только к этому набору, не является гарантией 97% качества любых сайтов.
