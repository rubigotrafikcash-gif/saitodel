# Сайтодел 1.0.2

Навык и приватный плагин для создания, переработки и проверки сайтов. Сохранены бриф, CTA, адаптив, Словодел, три роли и независимая приёмка.

[Аккаунтная поставка](https://chatgpt.com/plugins/plugins_6af0b6fc62bc81918d18cb8ee0227cea) · [Текущий статус](docs/INTEGRATION_STATUS.md) · [34 критерия приёмки](tests/acceptance.md)

## Подключённые материалы

- Полные MotionSites и семь выбранных навыков TheGoat — вместе с обязательными references/scripts и лицензиями.
- Полные правила Vercel, адаптированные для русской редакторской нормы и доступного zoom.
- Полный web-design-engineer — обязательное получение из закреплённого внешнего источника. Из-за отсутствия указанной upstream лицензии его копия не распространяется в пакете.
- Точные версии/хеши: sources.lock.json. Порядок применения: references/integrated-skills.md.

## Состояние

Сохранение и чтение аккаунтной версии подтверждены. Состав принят независимо: 8/8,68 файлов account readback совпали. Это не результат всей приёмки; 97% общего набора пока не подтверждены. Отдельный запуск Codex блокируется правами текущей среды; обнаружение в новой Work-сессии требует проверки. Исторический персональный навык не считается обновлённым.

Испытание исходников на синтетическом сайте находится в tests/artifacts/. Самопроверка, независимая оценка и установка учитываются отдельно. Пилот Натальи и реальный телефон остаются отдельными невыполненными проверками.

## Подготовка и запуск

Используются существующие Node и Codex CLI. Сборка без npm-зависимостей:

```powershell
node scripts/package.mjs build/new-release/saitodel
node scripts/source-manager.mjs verify .
node --test tests/source-manager.test.mjs
```

Для установки на Windows из обычного PowerShell пользователя:

```powershell
& 'C:\Users\rust\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoProfile -File .\scripts\Install-Saitodel.ps1 -CodexPath 'C:\Users\rust\AppData\Local\OpenAI\Codex\bin\f71a721e0e6193a9\codex.exe' -NodePath 'C:\Program Files\nodejs\node.exe' -RunTests
```

Команда выполняется из корня этого репозитория на ноутбуке, пользователем rust. Путь PowerShell7 найден и проверен в текущей среде. Политика Windows PowerShell5 запрещает запуск скриптов; установщик её не меняет. После подтверждения установки флаг -RunTests запускает отдельные процессы Codex P1–P4. Скрипт сохраняет точные промпты, ответы, stdout/stderr и exit codes; не присваивает им PASS. Итог оценивается независимо по замороженным критериям, включая реально прочитанные навыки и браузерные действия. Старый/неоднозначный установленный Сайтодел останавливает установку до выяснения личности пакета, без создания дубля.
