# Сайтодел 0.2.0 — отчёт о подготовке выпуска

Дата: 8 ноября 2026 года. Задачи: [#1](https://github.com/rubigotrafikcash-gif/saitodel/issues/1), [развёртывание на устройствах #3](https://github.com/rubigotrafikcash-gif/saitodel/issues/3).
Основание: пользователь поручил довести навык до готовности публикации в GitHub как 0.2.0 и добавить подзадачу для ноутбука, браузера и телефона.

## Изменения

- Сохранены четыре режима: новый сайт, переработка, аудит, мастер-промпт; бриф, аудитория, CTA, концепция, адаптив и проверка результата.
- Добавлены контракты координатора, исполнителя и отдельного проверяющего, фиксация версии, общий счётчик исправлений и восстановление контекста.
- Согласованный регламент v1.0 и четыре прежних reference-документа сохранены побайтно.
- Созданы manifest плагина, единый шаблон записи работы и сборщик двух архивов из одного источника. Сервер, MCP, hooks и новые API не добавлены.
- Удалены устаревшие значения products в интерфейсных метаданных. SVG получает размер 48×48; векторный рисунок не изменён.
- Добавлены проверки упаковки и план отдельного развёртывания на устройствах. Их наличие не подтверждает установку.

Frontmatter и openai.yaml используют JSON mapping, совместимый с YAML 1.2. Проверяется используемый проектом контракт; универсальный YAML parser и полный автоматический JSON Schema validator не запускались.
Независимый проверяющий отдельно сопоставил manifest с канонической схемой Agent Plugins.

Для проверки поведения использован отдельный агент без истории разработки. Он получил исходные инструкции и синтетические входы; ожидаемые ответы и контрольные дефекты ему не передавались.
До выполнения зафиксированы [критерии](forward-criteria.json) и [входные хеши](fixture-sha256.json); после выполнения — [хеши результатов](forward-sha256.json).
В аудите обнаружены неверный адрес CTA, мобильная минимальная ширина и невозможность закрыть меню. Рендер и реальные взаимодействия не объявлены проверенными.
Мастер-промпт сохраняет бриф, а возобновление сохраняет BLOCKED и 2/2 циклов именно учебного задания. Этот учебный счётчик не является счётчиком разработки пакета.
Это выполненные задания с загрузкой инструкций из source, а не установка навыка, сравнение моделей или испытание в каждом целевом клиенте. Три задания выполнялись одним отдельным агентом последовательно; независимый проверяющий оценивал готовые результаты отдельно.

Core «Словодела» не выдаёт автоматическое разрешение публикации: `publication_ready=false`; JSON Schema validation недоступна без jsonschema, семантическую приёмку verifier не выполняет.
Предупреждения о квадратных скобках разобраны: это подписи Markdown-ссылок, номера источников, поля шаблонов и цитируемый запрет заглушек. Они не означают незаполненные части самого выпуска.
Факты и ограничения проверялись чтением источников и отдельной инженерной приёмкой. Машинные метрики не используются как оценка убедительности текста.

## Команда и бюджет

Координатор и исполнитель упаковки: `/root`. Исполнитель инструкций: `/root/architecture`.
Независимый проверяющий: `/root/independent_review`, не автор реализации. Исполнитель отдельных заданий: `/root/forward_execution`, новый контекст без истории разработки и ожидаемых ответов.
Одновременно работали максимум три агента; вложенные команды не создавались. Один владелец каждого изменяемого файла; core был заморожен на время приёмки.
`initial_review_done=true`, `fix_cycles_used=2` из 2. Первый цикл исправил размер иконки и его проверку; второй уточнил формулировки двух итоговых документов. Исходники и архивы после первого цикла не менялись.
Повторные проверки выполнялись по изменённым файлам и новому поведению; исторические ошибки установки не воспроизводились без изменения условий.
Модель/effort использованы по умолчанию среды; точная стоимость и расход токенов в этой работе не измерены.

## Границы готовности

Подготовка исходников и ZIP — отдельный результат от установки в аккаунт, выполнения в клиенте и публикации в каталоге OpenAI.
Исторические записи от 13.10.2026 описывают создание и использование персонального навыка; текущая установка и backend ID плагина ими не подтверждены.
Штатная установка ранее блокировалась правами записи и DNS; дубликат не создан, права и сеть не изменены.
Локальный Codex, web Work/Chat и телефон пока не имеют подтверждённого запуска версии 0.2.0. Для них открыта [#3](https://github.com/rubigotrafikcash-gif/saitodel/issues/3) с [порядком и критериями](../../cross-surface-rollout.md).
Пилот на сайте Натальи, просмотр реального сайта, пользовательское исследование и публикация сайта не выполнялись.

При обновлении существующей установки сохранить её прежнюю версию и идентичность. Откат исходников — отдельным обратным коммитом после проверки последующих изменений, без force push; откат установки выполняется штатным способом конкретного клиента после её подтверждённого обновления.
