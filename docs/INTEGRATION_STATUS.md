Полный внешний web-design-engineer (4 файла) получен и проверен; его копия не включена в поставку, поскольку upstream не указал лицензию. Все source refs и пути находятся в sources.lock.json.

Plugin Management ответил already_installed. Это НЕ подтверждение обновления исторического персонального навыка от 13.10.2026: его идентичность не установлена. Не создавать следующую копию и не удалять неизвестную историческую установку.

В текущем каталоге навыков новая поставка пока не обнаруживается; прямое чтение skill package недоступно. Испытание исходников по явному пути не засчитывать как новую сессию с нативным обнаружением.

## Проверки и воспроизведение

Фиксированные критерии: tests/acceptance.json, 34 проверки, все critical обязательны; порог PASS/34 >=97%, blocked/not_run не исключать. Нет доказательств, что порог пройден. Component tests source-manager: 5 PASS, 1 NOT_RUN (symlink EPERM); это отдельные тесты, не 34 сценария.

Команды в PowerShell из корня исходников:

    node scripts/source-manager.mjs verify .
    node scripts/source-manager.mjs verify-remote ../saitodel-external
    node --test tests/source-manager.test.mjs
    node scripts/package.mjs build/<новая-папка>/saitodel

Внешний cache не публикуется в репозиторий или плагин. При отсутствии cache получить полные закреплённые файлы через GitHub connector и проверить возвращённые blob SHA; либо использовать prepare-remote в доступной сети.

## Установка на ноутбуке

Штатный установщик scripts/Install-Saitodel.ps1 собирает отсутствующий пакет, проверяет встроенные source hashes, сохраняет копию config.toml перед регистрацией, регистрирует personal-saitodel и устанавливает saitodel. Он не обходит права и не меняет настройки безопасности. При обнаружении исторического отдельного навыка saitodel сначала сопоставить его идентичность и выбрать одну активную установку; не удалять без поручения.

Запуск: обычный PowerShell пользователя rust на ноутбуке, а не VPS. После успешной установки проверить новую сессию Codex и повторить P1–P4 из acceptance.json; отдельно проверить обнаружение и запуск в Work. Текущая ошибка доступа сама не исчезла.
