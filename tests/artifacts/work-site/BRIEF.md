# «Линия» — локальный демонстрационный сайт

Дата: 8 ноября 2026. Исполнитель: Work, субагент website_work_p1.

Цель: представить небольшую студию сайтов для владельцев кафе, салонов и сервисных компаний; привести к кнопке «Обсудить проект» и ясно обозначенной локальной форме с именем и email. Никакой внешней публикации или отправки данных.

Обязательные разделы: первый экран, услуги, этапы, FAQ, форма. Запрещены выдуманные клиенты, отзывы, цены, показатели и контакты.

Выбрано редакционное направление: молочный фон #f5f3e9, тёмно-зелёный #173c32, крупные заголовки Georgia, основной текст Segoe UI; контрастные поля, тонкие линии, спокойная асимметрия. Альтернативы: строгая модульная сетка (менее выразительна) и фотоподача локальных заведений (потребовала бы дополнительных материалов). Текущий бриф позволяет сразу реализовать выбранный вариант без повторного согласования.

Система: шаг отступов 8px; закругления 4px для кнопок, без карточек ради карточек; без теней, автозапуска и анимаций появления. Только короткое смещение стрелки по наведению, отключаемое reduced motion. На узком экране типографика уменьшается, навигация остаётся видимой, блоки меняют структуру.

Стек: автономные HTML/CSS/JS без npm-зависимостей и внешних ресурсов; небольшой локальный сервер Node.js только для просмотра. Форма запускает проверку полей и выводит честное подтверждение демонстрации. CSP запрещает отправку форм и сетевые подключения. Нет хранения данных.

Приёмка: рабочие якоря/CTA, все разделы, клавиатура, ошибки/успех формы без запросов, раскрытие FAQ, отсутствие горизонтальной прокрутки на 320px, 390px, планшете, ноутбуке, большом и коротком экране; просмотр рендера, консоль/сеть, reduced motion, no-JS и увеличение текста. Реальные мобильные устройства, Safari и тест с человеком не заявляются.
