# Линия

Автономный локальный одностраничный сайт. Откройте `index.html` в браузере: все стили, FAQ и демоформа работают без сборки и внешних подключений.

Для локального HTTP-просмотра из этой папки в PowerShell:

```powershell
node server.cjs
```

Адрес: http://127.0.0.1:4173. Сервер запущен при испытании, но доступ к loopback из инструментальной среды заблокирован (`ERR_NETWORK_ACCESS_DENIED`); фактический браузерный прогон выполнен через `file://`. HTTP-доставка не подтверждена и не заменена утверждением о публикации.

Форма проверяет имя и email локально. Она не отправляет и не сохраняет данные. Без JavaScript кнопка остаётся выключенной; CSP запрещает отправку формы и сетевые подключения. На экране до и после действия явно описан деморежим.

Исходники: `index.html`, `styles.css`, `app.js`, `favicon.svg`, `social-preview.svg`; локальный сервер `server.cjs`. `verify.cjs` — основной фактический браузерный прогон, `verify-final.cjs` — узкая проверка последних двух исправлений.

Согласованный бриф: `BRIEF.md`. Источники и решения: `SOURCES.md`. Результаты и ограничения: `CHECKS.md`. Исходный неуспешный прогон сохранён в `checks/`, успешный и исправления — в `checks-final/`.

Публикация не выполнялась. Перед коммерческим использованием нужно подтвердить услуги/контакты/условия, подключить согласованную обработку формы и подготовить абсолютные адреса social preview. SVG-превью локально доступно; приём сторонними социальными платформами не проверялся.
